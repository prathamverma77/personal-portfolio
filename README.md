# 🚀 Pratham Verma — Personal Portfolio

A sleek, responsive, and high-performance developer portfolio built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- ⚡ **Instant Resume View**: Background pre-fetching and edge caching for zero-delay PDF opening.
- 🎨 **Modern Design**: Custom dark-mode theme, ambient glow effects, and smooth micro-animations.
- 💼 **Projects Showcase**: Interactive section highlighting full-stack web applications and live demos.
- 🛠️ **Tech Stack Grid**: Dynamic display of frontend, backend, database, and cloud tools.
- 📈 **GitHub Contributions**: Live GitHub contribution calendar integration.
- 📬 **Interactive Contact**: Direct inquiry form with real-time feedback.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling & Motion**: Tailwind CSS v4, Framer Motion, React Icons
- **Backend & Storage**: Next.js API Routes, MongoDB Atlas, Cloudinary
